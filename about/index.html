About

This Digital Garden

This is my second brain—a place to externalize thoughts, ideas, and learnings. It's built on the Zettelkasten method, a note-taking system that emphasizes connections between ideas rather than hierarchical organization.

The content here is a living, breathing collection. Notes evolve, connections form, and ideas mature over time. Some notes are polished essays, others are raw explorations. That's the nature of a digital garden.

The System

I organize my notes into three main categories:

  • Reference Notes: Highlights and excerpts from articles, books, and other sources I've consumed.
  • Literature Notes: Ideas from references explained in my own words, showing I've processed and understood the concepts.
  • Permanent Notes: Original thoughts and connections between ideas, the synthesis that emerges from engaging with the material.

The Stack

This site is built with Astro, a modern static site generator that ships zero JavaScript by default. The content lives in markdown files that I edit with Obsidian, my note-taking tool of choice.

The design emphasizes readability with a muted color palette, generous whitespace, and typography optimized for long-form reading.
